Grove is a native Android companion for Emacs org-mode users. Every note is a plain `.org` file on disk — Grove never introduces a proprietary format, and its local index is fully rebuildable from those files at any time.

This section documents every feature currently implemented in the app, one page per feature, with real screenshots from the app itself.
