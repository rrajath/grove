Settings → Look and Feel is where Grove's visual presentation is configured — separate from note *content* settings like TODO keywords (see [Notes Behavior](/features/notes-behavior)).

## Themes

Grove ships 11 built-in palettes, picked from a dropdown:

**Light themes:** Grove Light, Tokyo Day, Catppuccin Latte, Rosé Pine Dawn
**Dark themes:** Grove Dark, Tokyo Night, Synthwave, Dracula, Catppuccin Mocha, Nord, Rosé Pine Moon

There's no "follow system" auto option — theme selection is always explicit. Each theme defines a full token set (background, surface, ink/text, accent, and semantic colors for green/amber/red/blue/violet), so every screen in the app — including org-syntax highlighting in the editor — reflects the chosen theme consistently.

## Launcher icon theming

The **Sync App Icon with Theme** toggle swaps the app's launcher icon (and the brand mark in the nav drawer) to match the active theme, using Android's `activity-alias` mechanism. Because of how icon aliasing works on Android, this requires the app to background and restart to take effect — it won't update the icon instantly while Grove is in the foreground. Note: the notification-shade icon can't follow the theme on Android 16+, a platform limitation rather than something Grove controls.

## Font size

A three-way segmented control: **Small / Medium / Large**, applied app-wide.

## Default note mode

Choose whether tapping a note from Outline View opens it in [Read](/features/read-mode) or [Edit](/features/edit-mode) mode by default.

## Display toggles

- **Show preface** — whether file-level `#+KEYWORD:` lines render in Read mode
- **Show property drawers** — whether `:PROPERTIES:` drawers render in Read mode
- **Show file icons in notebooks**: whether each row of the [Notebooks](/features/notebooks) list carries its icon tile. On by default; turn it off for a plainer, text-only list. The per-notebook icon and color you pick are kept either way, they just aren't drawn while this is off.

All three are display-only; turning them off doesn't remove anything from your files or settings, it just hides that element from the view.
