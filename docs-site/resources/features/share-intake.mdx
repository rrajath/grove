title: Share Intake
description: Send a link or text into Grove from any other app via the Android share sheet.
---

Grove registers as a target in the Android share sheet, so you can capture a link or selection from a browser, another app, or anywhere else without switching to Grove first and starting a capture manually.

## How it works

Sharing to Grove opens the [Capture picker](/features/capture) with the shared content already available to templates:

- The first shared **URL** becomes `%shared_url` — Grove also fetches the page title in the background so a template can reference it
- Any remaining shared **text** becomes `%shared_text`

Pick a template as normal; whichever placeholders it uses pull in the shared content automatically.

## Default target file

Settings → Sharing lets you set a **default target file** for shared content, so shares can land somewhere predictable even before you've built out a dedicated share-specific template.
