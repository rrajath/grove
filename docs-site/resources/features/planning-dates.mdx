Planning Dates is Grove's full-screen editor for a heading's SCHEDULED and DEADLINE timestamps. It opens from the Schedule/Deadline pill in the [Metadata Sheet](/features/metadata-sheet), from Outline View's Schedule swipe action, from Search's swipe action, and from reminder notifications' Reschedule action.

![Planning Dates screen for "Finish Q3 roadmap deck" showing a shorthand entry field, quick-token chips, a July 2026 calendar with Jul 31 selected, preset buttons, Time/Repeat toggles, and an org-syntax preview footer](../assets/planning-dates.png)

## Shorthand entry

The text field at the top accepts compact shorthand instead of tapping through the calendar:

- `d:` prefix targets DEADLINE, `s:` targets SCHEDULED (the field defaults to whichever the "taps set..." indicator below the calendar currently points at)
- Relative tokens like `+2w`, `++1w`, `fri`, `aug 3`, `10-11am`, `d: mon` — tapping any of the quick-token chips inserts it into the field
- **Set** applies the parsed value immediately

## Calendar

A month grid below the shorthand field. Tapping a date sets whichever of SCHEDULED/DEADLINE the toggle at bottom-left of the calendar ("taps set SCHEDULED") currently targets. Scheduled and deadline dates are color-coded (blue dot / red dot per the legend) so you can see both on the same month at a glance.

## Presets

Below the calendar, one-tap presets for the most common targets: **Today**, **Tomorrow**, **This weekend**, **Next week** — each labeled with the resolved date.

## Time and Repeat

- **Time** toggle switches between all-day and a specific time range
- **Repeat** toggle exposes the org repeater cookie editor (`+1w`, `++1m`, `.+3d`, etc.) for recurring tasks

## Preview footer

A raw org-syntax preview (`SCHEDULED: <2026-07-31 Fri>` / `DEADLINE: -`) sits above the action button, so you can see exactly what will be written before committing. The action button's label adapts to what's set — **Apply Scheduled Date**, **Apply Deadline**, or **Apply Both Dates** — and **Clear** in the top-right removes both.
