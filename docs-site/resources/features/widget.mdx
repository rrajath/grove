Grove ships a Glance-based Android app widget for the home screen — a single button that opens the [Capture picker](/features/capture) directly, skipping the app's own navigation entirely.

## Adding the widget

Long-press your home screen, choose **Widgets**, and find Grove in the list. It's a fixed-size single-purpose widget — there's no configuration screen, since its only job is to open Capture.
