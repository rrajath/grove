Dailies gives you one note per calendar day, separate from browsing notebook-by-notebook. Where the Notebooks list is organized by file and the Outline by heading, Dailies is organized by date: open it and you land on today's note, with the whole vault's days one swipe away in either direction.

## Enabling Dailies

Dailies lives under Settings → Roam Features → Dailies, and only appears once Roam Features are turned on. Three fields configure it, and all three have working defaults — Dailies works with zero configuration beyond turning Roam Features on:

- **Dailies location** — the vault-relative folder new daily notes are created in. Leave it blank to create them at the vault root.
- **File name pattern** — the `FilenamePattern` tokens used to name each day's file, for example `%<%Y-%m-%d>.org`.
- **Header template** — the content a brand-new day's file is seeded with, expanded through the same placeholder syntax as capture templates. `%?` marks where the cursor lands after creation.

## Opening Dailies

With Roam Features and Dailies both configured, a **Dailies** row appears in the nav drawer, positioned just above Agenda. Unlike every other drawer row, which fills solid when it's the active route, the Dailies row always carries a thin accent border rather than a fill — it opens a different note every day, so there's no single fixed destination to mark "active." The row's trailing edge shows today's date in short form.

## Navigating between days

Inside Dailies, move between days three ways:

- **Swipe left or right** on the note body, in both Read and Edit mode, to move to the next or previous day. Swiping right goes to the previous day, swiping left to the next.
- **Prev / next pills**, floating over the bottom-left and bottom-right corners of the screen (hidden while the keyboard is up), give the same navigation with an explicit tap target, each labeled with its date.
- **Tap the calendar icon**, always visible in the top bar, to jump straight back to today.
- **Long-press the calendar icon** to open a date-picker sheet and jump to any date directly.

"Next" always moves exactly one day forward. "Previous" (the pill and swipe-right) instead jumps to the most recent day that actually has a note — it's not always exactly one day back. On a vault with gaps between daily notes, this can skip over empty days.

If you're mid-edit with unsaved changes, navigating away with a swipe, a pill, the calendar icon, or the date picker all route through the same dirty-edit leave-confirmation guard as backing out of the screen, so a swipe can never silently discard changes.

## The top bar

- The date title shows a **TODAY** pill next to it when you're viewing today's note.
- A **Read/Edit toggle** switches between the rendered note and the raw editor, same as everywhere else in Grove. You can also **double-tap** anywhere on the note in Read mode to jump into Edit mode.
- A **Save icon** appears next to the back button while in Edit mode: green while there are unsaved changes (tap to save immediately), muted once saved.
- The **calendar icon** (see above) is always visible: tap to jump to today, long-press to open the date picker.

## Empty days

A day with no note yet renders an empty state instead of a blank editor: "Nothing here yet. Tap to start typing and create `<filename>`." Tapping it doesn't create the file immediately — it seeds an in-memory editor buffer from the header template and drops you straight into editing. The file itself is only written to disk on the first autosave (about five seconds after you stop typing) or a manual save. The empty state also reminds you that long-pressing the calendar icon opens the date picker, in case you meant to land on a different day.

## Linked References

If Roam Features' backlinks are turned on and the day's note is a roam-linked file, a Linked References bar sits at the bottom of the screen, same as in Read/Edit Note elsewhere in the app. It shows counts of linked and unlinked references to the current day; tapping it opens the full references sheet.
