## Custom TODO keyword sets

Grove's default keyword set is `TODO IN-PROGRESS | DONE CANCELLED`, using standard org-mode syntax: keywords before the `|` are "not done" states, keywords after are "done" states. You can redefine the whole set in this syntax (for example `TODO NEXT WAITING | DONE KILL`) and it propagates everywhere keyword chips are shown (Outline View, Read/Edit mode, the metadata sheet's State picker, Agenda's Show filter).

## Default priority

Sets which priority (none, A, B, or C) new headings start with.

## Default note mode

Choose whether tapping a note from Outline View opens it in [Read](/features/read-mode) or [Edit](/features/edit-mode) mode by default.

## Font size

**Read mode** and **Edit mode** have their own Small / Medium / Large control. Each one scales only that surface: picking a larger read-mode size enlarges the rendered note without changing the editor, and vice versa. The rest of the app (screen titles, lists, settings, menus) always stays at its default size.

Medium is the default and matches the size the app has always used.

## Read-mode display toggles

- **Show preface**: whether file-level `#+KEYWORD:` lines render in [Read mode](/features/read-mode)
- **Show property drawers**: whether `:PROPERTIES:` drawers render in Read mode

Both are display-only; turning them off hides that element from the view without touching your files.

## Note IDs and timestamps

- **Add ID to new notes**: stamps a unique `:ID:` property on newly created headings, useful for stable `[[id:...]]` links that survive renames
- **Add CREATED timestamp**: stamps a `:CREATED:` property with the creation time

## Auto-archive

**Auto-archive done items** automatically [refiles](/features/refile) headings to a configured archive location once they're marked DONE, keeping active notebooks from accumulating completed clutter. The archive destination is chosen the same way as a manual Refile target.

The destination is looked up in this order, first match wins:

1. An `:ARCHIVE:` property on the heading itself, or on its nearest ancestor
2. An `:ARCHIVE:` in the file's top `:PROPERTIES:` drawer, then a `#+ARCHIVE:` line
3. The archive location set in Settings, only while **Auto-archive done items** is on

A location looks like `file::* Heading/Subheading`. `%s` stands for the current file, so `%s_archive::` archives `agenda.org` into `agenda.org_archive`, just like Emacs. A file name with its own extension is used exactly as written. Only a bare name like `archive` becomes `archive.org`. Missing files and headings are created. Files that don't end in `.org` stay out of Grove's notebook list, search, and agenda.
