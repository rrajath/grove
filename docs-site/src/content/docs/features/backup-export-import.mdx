Settings → Backup covers Grove's own configuration, not your notes. Your `.org` files are already durable, plain-text, and synced independently (see [Sync](/features/sync)); this screen is for everything else: themes, templates, keyword sets, swipe-action bindings, and so on.

## Export

Writes every configured preference to a single JSON file: theme selection, font size, custom TODO keyword sets, default priority, capture templates, sync folder and mode, Agenda swipe-action bindings, reminder settings, sharing defaults, and any other Settings-page value.

## Import

Reads a previously exported JSON file back in, restoring the full preference set in one step, useful when setting up Grove on a new device, or recovering after a reinstall.

Because this covers *every* settings surface, any time a new setting is added anywhere in the app, the export/import logic is expected to be updated to include it, so a backup taken on one version stays complete going forward.
