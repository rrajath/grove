Agenda pulls every SCHEDULED and DEADLINE item across your whole vault into a single day-by-day timeline, separate from browsing notebook-by-notebook. Bare active `<date>` timestamps (events) join it too, each shown on its exact day with a violet `●` chip.

## Today / Upcoming tabs

- **Today**: everything scheduled or due today, plus an **Overdue** card for anything past its date. Events only ever appear on their own day, never in the Overdue card
- **Upcoming**: an infinite-scroll timeline of future days, grouped under day headers like "Tuesday, Jul 28 · Today"

## Overdue card

Collapsible by default; expanding it lists every overdue item with a **Move to today** bulk action to reschedule everything at once.

## Row anatomy

Each row shows a priority-tinted checkbox (tap to mark done), the TODO/keyword chip, the title, a metadata line (date, "Xd late" for overdue items, tags), and a priority badge on the trailing edge. Tapping the row opens the note; tapping the checkbox toggles DONE in place.

A heading with no TODO keyword is an event, not a task, whether it lands on the day by a bare active `<date>` timestamp, a SCHEDULED date, or a DEADLINE. Events show no checkbox and no "mark done" swipe. A heading that carries a keyword is still a task and keeps both, even when it also has an active timestamp. When an event sits under a day heading, its metadata line drops the day (the heading already shows it) and keeps just the time range, if any.

## Levers panel

A collapsible panel above the list controls how items are grouped and filtered, and persists your choice between sessions:

- **Group by**: Date, Priority, Tag, or File
- **Show**: Open items only, specific configured keywords, or Everything
- **Display toggles**: show/hide tags and source-file names per row

## Swipe-to-commit

Swiping an Agenda row left or right triggers a configurable action: by default, swipe left sets a Scheduled date and swipe right marks the item Done. Both directions are reconfigurable in Settings → Agenda (see [Notes Behavior](/features/notes-behavior) for the settings surface). Every swipe mutation is reversible via an [undo snackbar](/features/undo).

On an event row, the side configured as Mark as Done offers Add note instead, since an event has nothing to complete.

## Home-screen widget appearance

Settings → Widget is a dedicated page for the home-screen Agenda ledger widget (not the [quick-capture widget](/features/widget)): background Transparency, how many Days ahead to show, per-row Filename/Tags/Priority toggles, and a Small/Medium/Large Font size, with a live preview below the controls that updates as you change them. These are independent of the in-app Levers panel above — changing how the widget looks never changes the Agenda screen. A shown filename contracts each nested folder to its first letter (`Work/Projects/notes.org` → `W/P/notes.org`); the file's own name stays whole.

The widget lists the same rows as the Today/Upcoming view: scheduled and deadline items, an Overdue section, and bare active `<date>` events on each day they fall. Event rows carry no mark-done circle, since an event is not a task, and no repeated day label under the row.
