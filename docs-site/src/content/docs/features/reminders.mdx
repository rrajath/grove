## Reminder notifications

When a heading's planning date arrives, Grove fires a system notification. Whether it reads as a task or an event, and which actions it carries, depends only on whether the heading carries a TODO keyword — not on which timestamp field (SCHEDULED, DEADLINE, or a bare active `<date>`) triggered it.

### Task reminders

A heading with a TODO keyword is a task: the notification reads "Your task is due now" and always carries both actions:

- **Complete**: marks the heading DONE directly from the notification
- **Reschedule**: opens [Planning Dates](/features/planning-dates) to set a new date

### Event reminders

A heading with no TODO keyword is an event: the notification reads "Your event is starting now" (or "starts in ..." for a lead time) and carries only **Reschedule** — unless the timestamp itself carries a repeater cookie (`<2026-09-11 Fri +1w>`), in which case it also gets **Complete**, which advances the timestamp's own date rather than marking anything DONE. A date-only event doesn't fire its own notification by default; it is folded into the daily digest for its day (turn on "Notify for tasks without a time" below to get a separate notification instead). A date range reminds you once, on its start date.

Tapping the notification body itself deep-links into the note in Read mode.

## Reschedule without opening the app

The Reschedule action opens Planning Dates inside its own transparent, taskless activity, not the main app. That means rescheduling from a notification never actually navigates into Grove; you set the new date and land right back wherever you were (home screen, another app, the lock screen).

## Daily digest

If enabled, Grove sends one daily notification ("You have X tasks due today") covering overdue items plus anything due today, including any date-only events on today's date. It fires at your configured default reminder time and deep-links straight to Agenda. If the count would be zero, the digest is suppressed rather than sending an empty notification.

## Notify for tasks without a time

By default, a SCHEDULED, DEADLINE, or active timestamp that lands on a day with no time of day is only counted in the daily digest. Turn on **Settings → Reminders → "Notify for tasks without a time"** to get a separate notification for each of them, fired at the default reminder time on its day. The daily digest keeps working alongside it. Only tasks whose day is today or later are notified; a date that has already passed stays silent.

## Permissions

A dismissible banner ([`ReminderPermissionBanner`](/features/reminders)) requests notification and exact-alarm permissions only when Grove first actually needs them (not proactively at first launch), so you're not asked for permissions before you've turned reminders on.

## Surviving a reboot

A boot receiver re-arms all scheduled alarms after the device restarts, and fires any reminder that was due while the device was off but hasn't been seen yet.

## Settings

Settings → Reminders covers: the enable/disable toggle, the "Notify me" lead time for timed reminders, the "Notify for tasks without a time" toggle, the Morning Brief (daily digest) toggle, the default reminder time (used by the digest and by any timestamp without an explicit time), and the permission banner.
