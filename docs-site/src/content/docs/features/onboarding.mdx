## Sync with Syncthing (recommended)

The onboarding card walks through the recommended setup, since Grove itself doesn't sync files across devices (see [Sync](/features/sync) for why):

1. Install Syncthing on the phone and your laptop
2. Share your org folder between the two devices
3. Point Grove at that folder: sync from there is automatic

## Choosing a folder

**Choose a local folder** opens the Android system folder picker (SAF). Whatever folder you choose becomes the vault: every `.org` file inside shows up on the [Notebooks](/features/notebooks) screen.

## Deferring

**I'll set this up later** skips folder selection entirely; Grove opens to an empty Notebooks screen, and the same folder-picker prompt is offered again from there whenever you're ready.
