* Features
# TAB folds a headline. It works here too — go on.
{{ arrowCap }} ** Capture :capture:templates:
Pick a template, fill the blanks, done. Grove splices the entry into the right file at the right spot — top, bottom, under a heading, or into a datetree it builds for you.
- FAB, share sheet, ongoing notification
- grove://capture deep link + launcher shortcuts
- %^{prompt} placeholders ask before they expand
{{ arrowAg }} ** Agenda :agenda:planning:
Every SCHEDULED and DEADLINE in the vault, collapsed into one day-by-day timeline. Overdue gets its own card, with Move to today for the mornings you need it.
- Group by date, priority, tag or file
- Swipe left to schedule, right to finish
- Every mutation gets an undo snackbar
{{ arrowSe }} ** Search :search:facets:
A query language, not a search box that shrugs. Facets for tags, keywords, priorities and dates compose the way you'd expect them to.
t.work + s.7d → scheduled this week, tagged work
d.overdue + p.A → the ones that hurt
{{ arrowSy }} ** Sync & conflicts :sync:syncthing:
Grove watches the folder. When your laptop and your phone both edited the same heading, it says so plainly and shows you both sides — instead of picking a winner and hoping.
- Any folder: Syncthing, Nextcloud, a USB cable
- Index is a cache; the files are the truth
- Nothing leaves the device on its own
{{ arrowRd }} ** Rendered, not dumped :reading:themes:
Read mode sets your notes in type: real headings, tag chips, priority badges, drawers folded away until you want them. Edit mode gives the raw text back, syntax-highlighted, whenever you'd rather see the asterisks.
- 11 palettes — Grove, Nord, Dracula, Rosé Pine, Catppuccin…
- Launcher icon follows the theme
